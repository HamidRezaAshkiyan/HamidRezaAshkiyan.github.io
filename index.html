// 03. System Blueprint

Distributed Systems & Modular Topology

How components communicate reliably through MassTransit, RabbitMQ, and atomic persistence.

01

Clean Architecture & DDD

Strict dependency inversion: Domain entities have zero external package dependencies. Application commands and queries are orchestrated with MediatR.

02

MassTransit & RabbitMQ

Decoupled asynchronous event delivery across services with automatic retries, exponential backoff, dead-letter queues (DLQ), and outbox message batching.

03

Transactional Outbox

Guaranteed at-least-once message delivery without dual-write hazards by saving domain state and outbox messages within one atomic SQL Server/Postgres transaction.

04

Idempotency by Design

Consumers guard against network duplicates using unique message IDs, distributed Redis locks, and deduplication inbox constraints.
